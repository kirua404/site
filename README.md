# School Harmony Hub

School Harmony Hub est une application web moderne conçue pour faciliter la gestion et la présentation de modules éducatifs, d'informations et de ressources pour les écoles ou organismes éducatifs.

## Fonctionnalités principales
- Présentation des modules et sections (À propos, Tarifs, FAQ, Témoignages, etc.)
- Interface utilisateur moderne et responsive
- Navigation fluide entre les différentes sections
- Composants réutilisables en React/TypeScript

## Installation

1. Clonez le dépôt :
   ```bash
   git clone <url-du-repo>
   ```
2. Installez les dépendances :
   ```bash
   bun install
   ```
3. Lancez le serveur de développement :
   ```bash
   bun run dev
   ```

## Structure du projet
- `src/` : Code source principal
  - `components/` : Composants React (sections, UI, etc.)
  - `hooks/` : Hooks personnalisés
  - `lib/` : Fonctions utilitaires
  - `routes/` : Définition des routes/pages
  - `assets/` : Images et ressources statiques
- `public/` : Fichiers publics

## Dépendances principales
- React
- TypeScript
- Bun
- Vite
- ESLint
